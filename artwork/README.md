# 64 型人格插畫

每型一張獨立的內建 imagegen 生成圖。角色、生活場景、配色與人格／卦義比喻依本案的 64 篇原創報告設計，未將第三方圖片作為生成輸入、拼貼素材或描摹底圖。文化與自然器物意象的公開參考頁列於 `art-direction/prompts-01-32.json`、`prompts-33-64.json`。

- `originals/`：內建工具輸出的 PNG；完整圖檔包另交付，不放進公開 Git 儲存庫。各型最終採用檔案以公開 manifest 的 `original` 欄位為準，第 64 型使用 `hexagram-64-v2.png`，第一版另保留供比對。
- `dist/assets/personality/twobu/`：本版供網站顯示的 WebP 公開副本，四角加上使用者提供的 TWOBU 標誌作為浮水印。原始生成 PNG 與未加浮水印的舊版備份私下保留，不隨本版公開副本發布。實際製作方式、尺寸與雜湊由本次發布紀錄及 manifest 核對。
- `art-direction/generation-*.json`：本機生成與檢查紀錄；含本機路徑，不隨公開儲存庫發布。
- `art-direction/artwork-manifest.json`：可公開的提示、構圖說明、參考頁、原圖與網站圖 SHA256、尺寸及檢查紀錄；網站圖與原始生成圖分開辨識。

原圖並非從網路下載的現成藝術品；外部來源僅用於查核《周易》古代意象，以及參考博物館標為 Public Domain 的自然器物概念。沒有要求模仿特定藝術家、現成品牌人物或商標。使用者提供 TWOBU 標誌作為本版來源標示；這不表示其他品牌或第三方權利已轉讓給本案。

第 38、64 型曾使用內建圖像編輯修正手臂連接，編輯指示保留於 manifest。原始生成 PNG 保持原檔；本次公開展示副本的浮水印處理另作紀錄，不將加上浮水印的副本冒稱未修改原圖。
